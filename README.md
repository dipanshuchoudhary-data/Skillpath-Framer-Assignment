# Skillpath Framer Assignment

This repository contains the actual Framer code components used for the Skillpath assignment.

## Structure

```text
skillpath-framer-assignment/
├── components/
│   ├── SkillpathCourses.tsx
│   └── SkillpathContactForm.tsx
├── README.md
├── .gitignore
├── LICENSE
└── .git/
```

## Included components

- SkillpathCourses.tsx
  - Live course fetching from the assignment endpoint
  - Loading, error, empty, and no-results states
  - Search and price sorting
  - Refundable badge control
  - Framer property controls

- SkillpathContactForm.tsx
  - Name, email, and message validation
  - Inline error messaging
  - Frontend-only success state
  - No backend integration

## Notes

- This is a Framer code component project, not a standalone React app.
- The repository is kept intentionally minimal so reviewers can inspect the original component logic directly.
- No fake Vite/Next.js app has been added.
